ระบบส่ง Gen code กำลังเชื่อมต่อ…

ส่ง Gen code ของคลิปคุณ

วางรหัสจาก TikTok เลือกสินค้า แล้วแนบลิงก์คลิป แบรนด์จะนำคลิปไปยิงแอดให้

หา Gen code ได้จากไหน
  1. เปิดคลิปในแอป TikTok แล้วแตะจุดสามจุด
  2. แตะ Ad settings (การตั้งค่าโฆษณา)
  3. เปิด Ad authorization (การอนุญาตโฆษณา)
  4. เลือกจำนวนวันที่อนุญาต แล้วแตะ Generate
  5. คัดลอกรหัสมาวางในฟอร์มนี้

ชื่อเมนูอาจต่างกันเล็กน้อยตามเวอร์ชันของแอป

GC Score ของคุณ

สะสม 1 GC ต่อ 1 คลิปที่แบรนด์ยิงแอดแล้วเกิดยอดขายตั้งแต่บาทแรก ยิ่งสะสมมาก ค่าคอมยิ่งเพิ่ม

ประวัติของฉัน

โค้ดทั้งหมดที่คุณส่ง พร้อมสถานะล่าสุดจากแบรนด์

โค้ดที่ครีเอเตอร์ส่งมา

ส่งเมื่อช่องสินค้าGen codeคลิปสถานะยอดขายหมายเหตุจัดการ

รายการที่ลบ

รายการที่ลบไม่นับในตาราง สถิติ GC และไฟล์ CSV และครีเอเตอร์จะไม่เห็นในประวัติ กดดึงกลับเพื่อคืนรายการพร้อมสถานะเดิม

ลบเมื่อลบโดยช่องสินค้าGen codeดึงกลับ

    แบรนด์

    แตะช่อง + โลโก้ เพื่อเลือกรูป โลโก้จะแสดงข้างชื่อบนหัวเว็บ

    ภาพแคมเปญ

      ภาพจะแสดงใต้โลโก้ในหน้าของครีเอเตอร์ แนะนำขนาด 1200 × 480 พิกเซล ภาพสัดส่วนอื่นจะถูกตัดขอบบนล่างหรือซ้ายขวาให้พอดี ใส่ได้สูงสุด 5 ภาพ

      ผู้ใช้และสิทธิ์

      • ครีเอเตอร์ ส่งโค้ดและดูประวัติของตัวเอง
      • แอดมิน ดูโค้ดทั้งหมด เปลี่ยนสถานะ ใส่หมายเหตุ และดาวน์โหลด CSV
      • เจ้าของ ทำได้ทุกอย่าง รวมถึงแก้สินค้า แบรนด์ ภาพแคมเปญ และกำหนดสิทธิ์
      ชื่อ LINEช่อง TikTokเข้าใช้ล่าสุดสิทธิ์

      คนที่จะเป็นแอดมินต้องเข้าสู่ระบบด้วย LINE หนึ่งครั้งก่อน ชื่อจึงจะขึ้นในรายการนี้
